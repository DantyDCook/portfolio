CareerOps Privacy Policy

CareerOps uses custom GPT Actions to access GitHub repositories
authorized by the user.

Data may be sent to GitHub's API solely to read or, when explicitly
authorized, write CareerOps repository content.

CareerOps does not sell user data.

Authentication credentials are used only to authorize GitHub API
requests and are not intentionally stored in CareerOps repository
content.

GitHub's handling of data is governed by GitHub's own privacy policy.

For questions about this CareerOps integration, contact the site owner.
