## Project Overview

This project analyzes bikeshare trip data across Chicago, New York City, and Washington using an R notebook workflow. It is a supporting portfolio project for exploratory analysis and BI-style visual communication.

## Problem

The project explores patterns in city-level bikeshare usage, including popular stations/routes, rider timing, and user-type differences where available in the datasets.

## Data / Inputs

The local evidence includes three 300,000-row city CSV files, generated PDF charts, and an R/Jupyter notebook. The total verified input size for this pass is 900,000 rows across the three city files.

## Architecture / Workflow

```text
City bikeshare CSV files
    -> R/Jupyter analysis
    -> grouping and comparison
    -> station, route, timing, and user-type visuals
    -> report-ready PDF outputs
```

## Key Capabilities Demonstrated

- Exploratory analysis across multiple datasets.
- Chart generation for transportation and usage-pattern reporting.
- Supporting BI storytelling with reproducible notebook artifacts.
